# Student Performance Analysis using Python

## Project Overview
This project analyzes students' performance in Mathematics, Reading, and Writing using Python. It uses Pandas and NumPy for data handling and calculations, and Matplotlib and Seaborn for data visualization.

The analysis includes descriptive statistics, total scores, percentages, average scores, pass/fail classification, and outlier detection for Mathematics scores.

---

## Dataset

The code reads a CSV file named StudentsPerformance.csv.

The dataset is expected to include these columns:
- math score
- reading score
- writing score
Other student-related columns may also be present and are included in the initial dataset inspection.

Note: The script currently loads the dataset from the Google Colab path "/content/StudentsPerformance.csv." If you run it locally, update the path to match where the CSV file is saved.

## Features
1. Load and inspect data
   - Read the CSV file.
   - Preview the first rows.
   - Check dataset dimensions, column names, and missing values.
2. Descriptive statistics
   - Calculate summary statistics for the score columns.
   - Calculate mean, median, mode, standard deviation, and the first quartile (25th percentile).
3. Score calculations
   - Calculate each student's Total Score by adding Mathematics, Reading, and Writing scores.
   - Calculate Percentage using Total Score / 300 * 100.
   - Calculate Average Score across the three subjects.
4. Pass/Fail classification
   - Label a student as Pass when all three subject scores are at least 40.
   - Otherwise, label the student as Fail.
5. Outlier detection
   - Use the Interquartile Range (IQR) method to identify possible outliers in Mathematics scores.
6. Visualization
   - Plot a histogram of Mathematics scores.
   - Begin plotting the Mathematics, Reading, and Writing score columns for comparison.

Key Calculations
### Total Score
```
df["Total Score"] = (
    df["math score"] +
    df["reading score"] +
    df["writing score"]
)
```
### Percentage
```
df["Percentage"] = (df["Total Score"] / 300) * 100
```
### Average Score
```
df["Average Score"] = df[
    ["math score", "reading score", "writing score"]
].mean(axis=1)
```
### Pass/Fail Rule
A student passes only if Mathematics, Reading, and Writing scores are all greater than or equal to 40.

### Mathematics Outliers
The script calculates Q1, Q3, and IQR for Mathematics scores, then flags values below Q1 - 1.5 * IQR or above Q3 + 1.5 * IQR.

## Limitations
- The dataset CSV must be available at the path specified in the code.
- The pass threshold of 40 for each subject is a rule used by this project; it may not match every institution's grading policy.
- Outlier detection identifies unusual values statistically; it does not automatically mean those values are incorrect.
- The supplied script ends while starting a plot of the three subject-score columns, so that visualization section may need to be completed.
