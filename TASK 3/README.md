# Shopify Stock Market Analysis using Python

## 📌 Project Overview

This project analyzes **Shopify stock market data** using Python to understand stock price movements, daily returns, trading volume, and unusual trading activity.

The project includes data loading, data exploration, data cleaning, return calculations, volume analysis, anomaly detection, statistical analysis, and data visualization.

---

## 🎯 Objectives

- Load and explore Shopify stock market data.
- Check the structure and summary statistics of the dataset.
- Handle missing values and duplicate records.
- Convert the date column into a proper datetime format.
- Calculate daily price changes and daily returns.
- Analyze trading volume.
- Identify anomalous trading days based on trading volume.
- Calculate mean, variance, and standard deviation of daily returns.
- Visualize stock price, trading volume, and return distribution.
