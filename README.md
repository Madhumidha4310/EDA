# Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project is an **Exploratory Data Analysis (EDA)** task performed on a Superstore dataset using Python.

The main focus of this task is to understand the dataset, perform basic data exploration and calculations, and represent the findings through different visualizations.

The analysis helps in understanding **sales, profit, discount, categories, and relationships between numerical variables** in the dataset.

---

## 🎯 Objectives

* Explore and understand the given dataset.
* Examine the structure and basic information of the data.
* Perform basic statistical analysis.
* Calculate category-wise sales and profit information.
* Analyze the distribution of profit.
* Study the relationship between discount and profit.
* Identify relationships between numerical variables using correlation.
* Represent the analysis using suitable visualizations.

# 🔍 EDA Process

## 1. Data Loading

The dataset was loaded into a Pandas DataFrame for analysis.

This provided the base data for performing the remaining EDA activities.

---

## 2. Data Exploration

The dataset was explored to understand its basic structure and contents.

The following aspects were examined:

* First few records
* Dataset dimensions
* Column information
* Data types
* Basic statistical summary

This step helped in understanding what type of data was available before performing further analysis.

---

## 3. Basic Calculations

Basic calculations and aggregations were performed to obtain useful information from the dataset.

The analysis included:

* Total sales by category
* Maximum profit by category
* Statistical information for numerical columns
* Correlation between numerical variables

These calculations were used to support the visual analysis.

---

## 4. Sales Analysis

Sales were analyzed based on **product categories**.

The category-wise sales calculation helps to understand how sales are distributed among the different categories in the dataset.

A **bar chart** was used to represent the category-wise sales.

---

## 5. Profit Analysis

Profit was analyzed to understand its distribution within the dataset.

A **box plot** was used to represent the profit values.

The visualization helps to observe:

* Distribution of profit
* Spread of values
* Central tendency
* Possible extreme values

Maximum profit was also examined for different categories.

---

## 6. Discount and Profit Analysis

The relationship between **Discount** and **Profit** was explored using a scatter plot.

This visualization helps to observe how profit values change across different discount levels.

### Visualization Used

**Scatter Plot – Discount vs Profit**

* X-axis: Discount
* Y-axis: Profit

---

## 7. Correlation Analysis

Correlation analysis was performed on the numerical columns of the dataset.

The purpose was to understand the relationships between numerical variables.

A **correlation matrix** was calculated and represented using a **heatmap**.
